# 理论支撑对照（经对抗式审查）

> 本工具每个阶段的机制都需要理论支撑,否则对专业受众没有说服力。
> **但核心原则是:少数顶梁柱钉死 + 其余诚实分级。过度背书(硬套、叠加、挂错名)比背书不足更伤可信度。**
>
> 所有理论已联网核实提出者/年份/主流性,并经一轮对抗式审查(挑误用、伪主流、认识论冲突)。
> 分级:✅顶梁柱(教科书级,大胆引用) / 🟡方法论立场(有标准支持,但非定律,如实说) / 🔧工程实践(有流程先例,不套理论) / ❌已砍(牵强,写了露怯)

## 🟡 方法论立场(有标准/框架支持,但如实说明不是"定律")

这些成立,但要用对措辞——说"我们采用 X 的原则/立场",不要包装成经过实验验证的科学规律。

| 阶段 | 机制 | 理论 | 正确措辞 |
|---|---|---|---|
| L1 | 采集停止 | **主题/数据饱和** + Guest 2006 操作化 | ⚠️ 说"主题饱和(thematic saturation)的停止规则",**不要说"理论饱和"**(见下方误用#1) |
| L1 | ≥2 类证据收敛 | **三角验证** Denzin 1978 | 说"采用三角验证的**收敛原则**,并自定义四类证据源"——不要说"我们的四类 = Denzin 四型" |
| L1 | observed>claimed>inferred | **GRADE-directness / 传闻规则** | 主锚用"证据直接性",EBM 金字塔只作"证据不等价"的元原则 |
| L1 | 中性标注(先描述后解读) | **扎根理论开放编码** | 只留开放编码(describe-before-interpret)。**Husserl 现象学已砍** |
| L2 | 横轴 = 用户任务 | **JTBD**(对齐 Ulwick ODI 可量化分支) | 定位为"分析框架/视角",不与 Fitts 并列称"科学理论"(JTBD 学术上被批不可证伪) |
| L2 | 纵轴 = 旅程阶段 | **客户旅程地图**(可上溯 Shostack 服务蓝图 1984) | 业界公认实践,学术锚点偏软,如实说 |
| L3 | 拒绝综合排名、场景级对比 | **ISO 9241-11**(可用性依赖使用情境) | 这是方法论立场 + 标准背书,不是"定律" |
| L4 | 认知成本 | **认知负荷理论** Sweller 1988 | 原属教学领域,UI 是被广泛接受的**外推**;construct 有争议,加注 |
| L4 | 决策成本 | **Hick 定律** 1952 | HCI 采纳度远低于 Fitts,仅"逐一审视选项"时成立,别当硬规律 |
| L4 | 机制解释(为何有效) | **Norman 可供性/意符/反馈/映射** 1988/2013 | affordance 源自 Gibson;signifier 是 2013 版才区分,引用标 2013 |
| L5 | 分级渲染/减负 | **渐进式披露 + 识别优于回忆** | 这两条强;**Miller 7±2 只作定性背书,禁止当"≤7项"的定量依据** |

## ❌ 已砍(牵强,写了反而露怯)

对抗式审查明确判定应删除的映射:

1. **现象学悬置 / Husserl** — 与扎根理论**认识论互斥**(反自然主义 vs 实证/实用主义)。想说"记录时先描述别下判断",单靠开放编码就够,拉 Husserl 是学术炫技。
2. **Myers 边界值分析** — "输入域数值边界"≠"交互流程边缘状态",同形异义偷换,行家一眼看穿。
3. **信息觅食 MVT 当检索指南** — 描述性理论当规范策略;且 MVT 停止规则与"饱和停止"是给同一个"何时停"贴两张理论标签,重复背书。二选一,只留饱和。
4. **Miller 7±2 的定量版** — "菜单≤7项"是对 Miller 的过度外推,Miller 本人否认。只留定性减负。

## 三处最需要向读者明说的诚实边界

1. **"数据/主题饱和" ≠ "理论饱和"**(最严重,曾差点挂错学派名)。理论饱和必须绑定"理论抽样",饱和的是理论范畴;我们的机制是"无新增即停",本质是主题饱和。老实用主题饱和,别蹭理论饱和的学术光环。
2. **四类证据 ≠ Denzin 四型**。只有"多源收敛提升效度"的原则来自 Denzin,四类标签是本工具自造。
3. **证据分层的轴 ≠ EBM 金字塔的轴**。EBM 按研究设计分级,我们按证据直接性分级;主锚应是 GRADE-directness 或法律传闻规则。

## 一句话方针

> 把 6 个顶梁柱(Camp / Fitts / κ·α / Nielsen 启发式 / 模式语言 / Mayer)钉死,大胆引用;
> 其余诚实降格为"方法论立场"或"工程实践";牵强的四条直接砍。
> **可信度来自"用对的少数",不来自"堆多的全部"。**
